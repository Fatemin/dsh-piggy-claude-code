🐖 DSH Piggy 桌面猪猪 · 使用说明
=====================================

一只住在你桌面右下角的小猪。它会饿、会脏、会生病，
要你喂它、给它洗澡、带它打工赚钱、上学、去旅行。

--------------------------------------------
一、安装
--------------------------------------------

【苹果电脑 Mac】用 “DSH Piggy-0.3.0-universal.dmg”

  1. 双击这个 .dmg 文件
  2. 在弹出的窗口里，把 “DSH Piggy” 图标拖到 “Applications（应用程序）” 文件夹
  3. 打开 “应用程序”，双击 “DSH Piggy”
  4. 如果弹窗说 “无法验证开发者” 或 “Apple 无法检查其是否包含恶意软件”：
       - 先点 “完成”（或 “取消”）
       - 打开 “系统设置” → “隐私与安全性”
       - 往下翻，看到 “已阻止 ‘DSH Piggy’ …”，点旁边的 “仍要打开”
       - 输入电脑密码，再点一次 “打开”
     这一步只需要做一次。
  5. 第一次打开要等几秒钟，然后猪猪就会出现在屏幕右下角，
     屏幕最上方的菜单栏里也会多一个小猪图标。

【Windows 电脑】用 “DSH Piggy Setup 0.3.0.exe”

  1. 双击这个 .exe 文件
  2. 如果出现蓝色窗口 “Windows 已保护你的电脑”：
       点 “更多信息” → 再点 “仍要运行”
  3. 它会自己装好并打开，桌面上也会有 “DSH Piggy” 快捷方式
  4. 猪猪出现在屏幕右下角；屏幕右下角的任务栏托盘里也有小猪图标
     （看不到的话，点任务栏上的 “^” 小箭头展开）

  ※ 这两个弹窗是因为这个小程序没有花钱买开发者签名，并不是病毒。

--------------------------------------------
二、怎么玩
--------------------------------------------

  ● 一开始是个纸盒 📦：戳它三下，或者右键点它再点 “拆开纸盒”
  ● 右键点猪猪：打开 / 关上菜单
       状态 · 学习 · 打工 · 商店 · 旅行 · 背包，六个图标点着玩就行
  ● 左键点猪猪：摸摸它
  ● 按住猪猪拖动：把它挪到屏幕任何地方（位置会记住）
  ● 猪猪以外的地方完全不挡鼠标，可以照常用电脑

  小贴士
  ● 喂食、洗澡、玩耍要先在 “商店” 里买东西，钱靠 “打工” 赚
  ● 猪猪靠吃东西长胖，越重个子越大：
       80 公斤变成老年猪，120 公斤长到最大（好好喂的话大概两周）
       变成老年猪以后，可以在 “状态” 页里切换 “老年猪 / 原版” 的样子
  ● 猪猪不会老死；但饿着或脏着太久会生病，生病要买对应的药
    （商店里会高亮提示），病太重也会死 —— 这时可以用 “还魂丹” 救回来
  ● 关掉电脑的时候猪猪照样在饿 —— 记得常回来看看它

--------------------------------------------
三、小猪图标的菜单
--------------------------------------------

  （Mac：点屏幕最上方的小猪图标；Windows：点任务栏托盘里的小猪图标）

  ● 显示 / 隐藏猪猪
  ● 猪猪回到右下角    —— 找不到猪的时候点这个
  ● 在浏览器里打开面板 —— 用大一点的窗口玩
  ● 开机自动启动      —— 打勾后每次开机猪猪自己出来
  ● 退出

--------------------------------------------
四、更新到新版本
--------------------------------------------

  直接安装新版就行，猪猪不会丢：
  Mac：先在小猪图标菜单里点 “退出”，再把新的 DSH Piggy 拖进 “应用程序”，
       提示已存在时选 “替换”
  Windows：先在托盘小猪菜单里点 “退出”，再双击新的 Setup.exe

--------------------------------------------
五、卸载
--------------------------------------------

  Mac：先在小猪图标菜单里点 “退出”，再把 “应用程序” 里的 DSH Piggy 拖到废纸篓
  Windows：“设置” → “应用” → 找到 DSH Piggy → “卸载”

  猪猪的存档在：
    Mac     ~/Library/Application Support/DSH Piggy/
    Windows %APPDATA%\DSH Piggy\
  卸载程序不会删掉它，重新安装后还是原来那只猪。
