# ST0003 · 睡觉 · design handoff

> 需求（用户原话）：新增睡觉：可以手动让猪去睡觉，或是电脑休眠时自动让猪睡觉，增加对应动画，睡觉状态下只掉饥饿，回复其他属性，生病几率只有平时的一半。

## 规则

| 项 | 决定 | 理由 |
|---|---|---|
| 进入 | 面板「😴 睡觉」/ `pig sleep` / 电脑 `suspend`（`auto: true`） | 需求 |
| 饱食 | 照常速度下降 | 「只掉饥饿」 |
| 心情、清洁 | 每分钟 +0.15 / +0.1，封顶 100 | 「回复其他属性」；8 小时约 +72 / +48，一夜能恢复但不会瞬间满 |
| 健康 | 不变 | 健康跟着疾病分期走（`STAGE_HEALTH`），不是可回复的条 |
| 生病 | 疏于照顾的累积分钟 × 0.5 | 生病不是随机数而是 `riskMinutes` 累积，「几率一半」= 累积速度一半 |
| 病程 | 不变 | 需求未提 |
| 叫醒 | 「☀️ 叫醒」/ `pig wake` / 照顾动作 / 出门 | 叫醒是最自然的回应；照顾被拒绝（冷却、没东西）时不叫醒 |
| 电脑唤醒 | 只结束 `auto` 的睡眠 | 手动哄睡的猪不该被电脑叫醒 |
| 不能睡 | 外出、死亡、还在纸盒里 | 外出与睡觉互斥 |
| 心情显示 | `asleep` 仅次于 `dead`，高于 `sick` | 按下「睡觉」后猪必须看起来在睡；生病仍在面板提示里写明 |
| 闲置打盹 | 原 `sleepy`（闲置 30 分钟）文案「睡着了」→「在打盹」 | 避免两个「睡着」 |

## 画面

- 新精灵 `assets/mood-asleep.svg`（`tools/build-sprites.mjs` 生成）：同一只 Noto 🐖，闭眼、蓝色睡帽带绒球、浅蓝小被子盖住下半身；4.4 s 慢呼吸带被子起伏，绒球晃动，右上飘 Z，左上月亮微光和两颗星闪烁。`prefers-reduced-motion` 时静止。
- 面板：照顾按钮下方一个通栏按钮，醒着显示「😴 睡觉」，睡着显示「☀️ 叫醒」；外出时禁用并标「不在家」。
- 睡着时所有标签页顶部一条淡紫提示：「😴 {name} 在睡觉 / 睡着时只会变饿，心情和清洁会慢慢恢复」，电脑触发的再加一行「跟着电脑一起睡的，电脑醒来它就起床」。
- 反应：睡觉飘 💤🌙、说「晚安…」；叫醒飘 ☀️、说「早上好！」。

## 范围外

- macOS 原生 SwiftPM 悬浮猪（`desktop/`）与 Claude Code 版不接系统休眠，只能手动睡。
- 饿到一定程度自动醒来：未做，睡着时饱食照常下降，生病风险减半兜底。
