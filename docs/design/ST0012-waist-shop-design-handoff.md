## 规则

| 项 | 决定 | 理由 |
|---|---|---|
| 部位 | `neck` 改名 `waist`，标签「腰上」；V1 未发布，原地修订 | 猪没有脖子；领巾类饰品一律画在腰上 |
| 腰的位置 | 顺着身体斜绕一圈：上端靠头、下端靠屁股、向后鼓出一道弧（用户画的线）；带子裁到身体轮廓内，不碰近耳；圈类同向倾斜 | 第一版竖直、落在前后腿之间，像绑在腿上；第二版压到耳朵（用户先后指出） |
| 圈类（呼啦圈、游泳圈） | 比身体大的椭圆环，近半圈画在身上，远半圈只在身体外露出（mask 掉身体） | 读得出“套在身上” |
| 获得方式 | 新解锁方式 `shop <price>`；买过的键存 `wardrobeBought`（可默认的新键，不升存档版本） | 用户要求“在商店中售卖”；进度解锁无法表达“买过” |
| 货架 | 商店新货架 `wear`「👗 装扮」，列 `WEAR_FOR_SALE`；不进 `SHOP` / `inventory` / 背包 | 装饰不是消耗品，不能“使用”，不该出现在消耗品里 |
| 购买 | 每件一次（`owned` 拒绝），买下立刻穿上（同部位换下）；货架显示「已拥有」 | 买完马上看到效果 |
| 价格 | 66 / 88 / 168 / 188 / 288（吉利数，量级在玩具与更名卡之间） | 纯外观，不影响数值 |

## 画面

- 商店最后一个货架「👗 装扮」：每行 emoji、名称、价格、「衣柜装扮，买一次一直有」，按钮「买」；已买的按钮置灰显示「已拥有」。
- 衣柜：没买的腰饰显示 🔒，悬停提示「在商店「装扮」货架买，N 金币」。
