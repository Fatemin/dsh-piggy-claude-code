# ST0004 · 装扮（衣柜）· design handoff

> 需求（用户原话）：新增装扮功能，将现在的学士帽等形象变化修改为装饰资产，允许用户自行组合佩戴。以后的设计和资产从契约层面区分装饰资产和行为资产。
>
> 用户选择：获得方式 = 按进度解锁（先只做这一种）；第一批 = 形象变化 + 姿势穿戴（8 件）；已在养的猪 = 自动跟阶段。

## 规则

| 项 | 决定 | 理由 |
|---|---|---|
| 部位 | head / eyes / neck / face，每部位一件；绘制顺序 face → neck → eyes → head | 「自行组合」= 跨部位组合；同部位两顶帽子画不对 |
| 解锁 | 只从已有进度推导（阶段按体重、上课数、毕业证、旅行次数、纪念品地区），不存档 | 用户选「按进度解锁」；不加存档字段，老猪的进度直接生效 |
| 默认 | `outfit: null` = 跟着阶段（小猪蝴蝶结、青年无、中年鸭舌帽、老年胡子） | 用户选「自动跟阶段」：更新后外观与之前一致 |
| 第一次搭配 | 把当前穿戴物化成玩家的 outfit 再改 | 点一下眼镜不应该顺手把蝴蝶结脱掉 |
| 姿势自带装备 | 姿势声明 `data-occupies`，该部位暂时不显示玩家装饰 | 旅行草帽、安全帽、护目镜是行为的一部分，与玩家帽子叠画会穿模 |
| 旧「老年猪 / 原版」 | 并入衣柜：`look` 只是戴上 / 摘下白眉白胡子；面板按钮由衣柜替代 | 一个外观入口；保留旧接口给旧面板与命令 |
| 合成位置 | 宿主美术路由 `?wear=`，面板只拼 URL | 所有宿主（DSH 面板、Electron、Claude Code 面板）都经这个路由取图，`<img>` 里的 SVG 动画照常；前端不碰 SVG 文本 |

## 画面

- 衣柜是**背包里的一格**，在「🎒 消耗品」右边（用户 2026-10-02 追加要求）：背包四格两行排列——消耗品 · 👗 衣柜 N/8 / 纪念品 · 毕业证，`N` 为已解锁件数。选中的格记在本地，和其他格一样。
- 衣柜格内：一行「正在穿的东西（或『什么也没穿』）」+ 右侧小按钮「跟着阶段」（跟着阶段时高亮）；下面四列药丸按钮，每件一颗：emoji + 名称。已穿高亮（同语言切换按钮样式），未解锁显示 🔒、虚线、灰色、不可点，悬停提示解锁条件。点击即穿 / 脱，屏幕上的猪就是预览。
- 死亡（墓碑）或旧宿主（快照没有 `wardrobe`）时背包不出现衣柜格；纸盒、墓碑、灵魂不穿任何装饰。
- 状态卡（命令行 / Claude Code）多一行「👗 穿戴 🎀蝴蝶结（跟着阶段）」。

## 范围外

- 商店购买装饰、旅行 / 打工概率掉落特殊装饰（`docs/TODO.md` 仍保留）。

- 睡觉时仍会戴着眼镜 / 墨镜（`mood-asleep` 只占用 head）；如需摘掉，给它加 `eyes` 占用即可。
