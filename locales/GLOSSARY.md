# Translation glossary (zh → ja · en)

Use these exact terms everywhere so the panel, the terminal and the tray agree.
Japanese: friendly, casual-polite game tone (like a Tamagotchi / どうぶつの森),
kana-heavy, です/ます only where a full sentence needs it. English: short, warm,
plain; sentence case in buttons.

The pig is referred to as "it" in English and by name or 「この子」 in Japanese.
